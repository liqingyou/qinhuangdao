# 方块龙城 · Block Qinhuangdao

> **Minecraft 方块风格 + GTA 城市漫游 + 宝可梦拍照收集** 的秦皇岛城市观光模拟器
> 无需出门，在浏览器里逛秦皇岛：自由行走、探索景点、拍照打卡、收集图鉴、体验龙城昼夜与四季风光。

🎮 **在线体验**：[https://liqingyou.github.io/qinhuangdao/](https://liqingyou.github.io/qinhuangdao/)

基于 **Vue 3 + Three.js (WebGL)** 实现，纯前端运行、无需服务器。

---

## ✨ 核心特色

- 🏙️ **还原秦皇岛城市格局** — 真实经纬度投影（现实 1km ≈ 游戏 200 格），7 大区县 + 渤海海岸线 + 方块化地形
- 📷 **摄影收集玩法** — 多视角相机 + 滤镜 + 自动识别景点，拍满图鉴做"龙城旅行家"
- 🚇 **城市生活模拟** — 观光巴士、轨道交通传送、渤海游船、联峰山索道、路人 NPC、海鲜美食
- 🌗 **昼夜与天气** — 晴/阴/雨随机变化，夜晚城市灯光与海面实时倒影
- 📱 **移动端适配** — 虚拟摇杆 + 触屏操作，竖屏提示横屏游玩、横屏一键全屏

## 🗺️ 已实现内容

### 世界地图

- 真实经纬度投影，1km ≈ 200 格，核心区 12km 外按比例压缩
- 覆盖 7 个区县：海港区 / 山海关区 / 北戴河区 / 抚宁区 / 昌黎县 / 卢龙县 / 青龙满族自治县
- 渤海海岸线、戴河、汤河、石河、洋河水系
- 主干道路网与桥梁，联峰山、祖山、碣石山方块地形

### 景点（13+ 个，S/A/B 三级）

| 级别 | 代表景点 |
| --- | --- |
| S | 山海关（天下第一关城楼、瓮城、钟鼓楼）、老龙头（长城入海处、澄海楼、龙武营）、北戴河海滨（金沙滩、日光浴场）|
| A | 鸽子窝公园（鹰角亭、观日出）、联峰山公园（望海亭、莲花石）、南戴河黄金海岸（滑沙场）、秦皇岛港 |
| B | 奥体中心、野生动物园、乐岛海洋公园、海阳路供电营业厅（海阳路265号）、祖山风景区、碣石山（曹操观海处）等 |

### 玩法系统

- **玩家角色**：方块小人，男/女、肤色/发型/服装自定义，支持上传 64×64 Minecraft 皮肤；WASD + 鼠标，奔跑跳跃，第一/第三人称
- **摄影系统**（`C` 键）：第一人称 / 第三人称 / 自拍（多种姿势）、6 种滤镜、变焦，自动识别画面中的景点并解锁图鉴，照片存入相册（IndexedDB，可下载）
- **NPC 路人**：上班族 / 学生 / 老人 / 游客 / 小孩 / 渔民，会走路、聊天、拍照、买东西、等公交，东北风格对白，可以合影
- **城市交通**：观光巴士（鸽子窝 ⇄ 北戴河 ⇄ 秦皇岛港 ⇄ 山海关）、轨道交通站快速传送、渤海游船、联峰山索道、城市车流
- **天气与时间**：晴 / 阴 / 雨随机变化，早晨 → 下午 → 黄昏 → 夜晚循环，夜晚窗灯与霓虹
- **收集与任务**：图鉴（建筑 / 食物 / 文化）、纪念品背包、新手任务链、区县任务、每日任务（按日期刷新）
- **性能优化**：分块流式加载、景点按距离加载/卸载 + 远景 LOD、合并网格、三档画质设置

## 🚀 快速开始

### 本地开发

```bash
# 1. 克隆仓库
git clone https://github.com/liqingyou/qinhuangdao.git
cd qinhuangdao

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

启动后访问 **http://localhost:5173/qinhuangdao/** 即可开始游戏。

### 构建与预览

```bash
# 生产构建（输出到 dist/）
npm run build

# 本地预览构建产物
npm run preview
```

## 🌐 GitHub Pages 部署

本项目已配置 GitHub Actions 自动部署。推送到 `main` 分支后会自动构建并部署到 GitHub Pages。

### 首次启用步骤

1. 进入仓库的 **Settings** 页面
2. 左侧菜单选择 **Pages**
3. **Source** 下拉框选择 **GitHub Actions**
4. 保存后，推送代码到 `main` 分支即可触发部署

部署完成后访问：**https://liqingyou.github.io/qinhuangdao/**

> 构建使用 `base: '/qinhuangdao/'`，确保资源在子路径下正常加载。

## 🎮 操作说明

### PC 端

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `Shift` / `空格` | 奔跑 / 跳跃 |
| 鼠标 | 旋转视角（点击画面锁定鼠标） |
| `V` | 切换第一/第三人称 |
| `C` | 进入/退出摄影模式 |
| `F` / 点击快门 | 拍照 |
| `1` – `6` | 摄影滤镜 |
| `E` | 交互 / 对话 / 乘车 |
| `T` | 时间快进 |
| `M` / `B` / `P` / `N` / `J` | 地图 / 背包 / 相册 / 图鉴 / 任务 |
| `H` / `Esc` | 帮助 / 关闭面板 |

### 移动端

- 左侧**虚拟摇杆**移动，右侧滑动旋转视角
- 右下按钮：跳 / 跑 / 交互 `E` / 摄影 📷 / 视角 👁
- **竖屏进入游戏会提示"请横屏操作"**（可选择仍要竖屏继续），旋转手机后自动进入横屏布局
- **横屏时底部菜单提供"⛶ 全屏"按钮**，一键进入全屏并锁定横屏方向（支持 Fullscreen API 的浏览器）
- 小提示：iOS Safari 不支持网页全屏接口时，全屏按钮会自动隐藏

## 📁 项目结构

```
qinhuangdao/
├── index.html              # 入口 HTML
├── vite.config.js          # Vite 配置（相对路径打包）
├── public/                 # 静态资源
└── src/
    ├── main.js             # 应用入口
    ├── App.vue             # 根组件（菜单/加载/游戏切换）
    ├── style.css           # 公共样式（MC 风格 UI）
    ├── components/
    │   ├── Menu.vue        # 主菜单 / 角色创建 / 出生点选择
    │   ├── GameView.vue    # 游戏主视图（HUD/摄影/移动端控制/横竖屏）
    │   └── Panels.vue      # 地图/背包/相册/图鉴/任务/设置面板
    └── game/
        ├── Game.js         # 游戏主循环与生命周期
        ├── world.js        # 世界生成（地形/水系/路网）
        ├── city.js         # 城市街区与建筑生成
        ├── landmarks/      # 各区景点建模（山海关/北戴河/海港/外围…）
        ├── player.js       # 玩家控制器与相机
        ├── character.js    # 方块角色与皮肤
        ├── npc.js          # NPC 行为
        ├── photo.js        # 摄影系统与滤镜
        ├── transport.js    # 巴士/轨道交通/游船/索道
        ├── physics.js      # 碰撞与移动
        ├── sky.js          # 天空/天气/昼夜光照
        ├── store.js        # 全局状态与存档（localStorage）
        └── …               # 输入、地图、材质、实例化等模块
```
